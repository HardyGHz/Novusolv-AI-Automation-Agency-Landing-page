🗺️ Sitemap & Robots Missing
CRITICAL
▼
No sitemap.xml found
GET /sitemap.xml → 404. Google cannot efficiently discover and index all pages. For a new domain, this can delay indexing by weeks.
Create a sitemap.xml at the root and submit it to Google Search Console. Vite plugin vite-plugin-sitemap can auto-generate this at build time.
Missing
No robots.txt found
GET /robots.txt → 404. Without this file Google crawlers have no guidance on how to traverse the site.
Create a public/robots.txt file (see Code Fixes tab for ready-to-paste content).
Missing
🧩 No Structured Data (Schema.org)
CRITICAL
▼
Missing Organization schema
No JSON-LD found in the page. Google can't surface rich results (business name, logo, social, contact info) in search.
Add Organization + LocalBusiness + FAQPage schema (see Code Fixes tab for full snippet).
Missing
FAQ accordion has no FAQPage schema
The 7 FAQ items are perfect for Google's "People Also Ask" featured snippets, but there is no FAQPage JSON-LD — a missed ranking opportunity.
Wrap each question/answer in FAQPage schema to trigger snippet eligibility.
Missing
⚙️ SPA / JavaScript Rendering
HIGH
▼
React SPA — all content is JS-rendered
The HTML served to crawlers is nearly empty (<div id="root"></div>). Googlebot can render JS but takes longer (days to weeks delay vs. static HTML).
Consider adding SSR or pre-rendering (e.g., via vite-plugin-ssr or migrating to Next.js). At minimum add react-helmet-async for robust meta tag management per route.
Warning
No <noscript> fallback
Users and bots with JS disabled see a blank page. A <noscript> fallback improves accessibility and crawl reliability.
Add a <noscript> block inside <body> with a short text summary of the page.
